# Phase 4 — UI Redesign Inspiration

## About the product
Rohan Energy Solutions — B2B ordering platform for DEF (Diesel Exhaust Fluid).
Customers are fleet operators, factories, mining companies. Staff are internal sales/ops team.

## Fill this in before redesign starts

### Brand feel (circle one or write your own)
- Clean / Professional / Industrial / Modern / Minimal / Bold / Friendly

### Primary audience
- Mobile-first customers on phones in the field
- Desktop-heavy staff in the office

### What the current design gets wrong

Imbalanced spacing, typography hierarchy is not clear, color palette is too limited and doesn't create enough contrast, components are inconsistent across screens.

### What must stay the same

Information architecture and user flows are solid, so the redesign should focus on visual design and UI patterns rather than changing the structure of the product.

## How to use this folder

| Folder | What to put there |
|---|---|
| `design/colors.md` | Hex codes, brand colors, color palette images |
| `design/typography.md` | Font names, sizes, any type samples |
| `design/components.css` | CSS snippets, component styles you want referenced |
| `screens/dashboard/` | Screenshots of dashboards you like |
| `screens/catalogue/` | Product grid / list UI screenshots |
| `screens/orders/` | Order list, order detail, timeline UI |
| `screens/auth/` | Login, OTP screens you like |
| `screens/mobile/` | Mobile app patterns, bottom nav, cards |
| `references/apps-i-like.md` | App names or URLs with notes on what you like |
| `references/dont-do-this.md` | Patterns to avoid |
